# Checklist de Cumplimiento FAIR (Anexo 2)

## F - Encontrables (Findable)
- [ ] ¿El conjunto de datos tiene un identificador persistente (DOI)?
- [ ] ¿Está publicado en un repositorio de acceso abierto y reconocido?
- [ ] ¿Cuenta con título y descripción clara en los metadatos?
- [ ] ¿Está indexado en catálogos visibles públicamente (ej. RE3data)?

## A - Accesibles (Accessible)
- [ ] ¿Se puede acceder mediante descarga directa o solicitud justificada?
- [ ] ¿El repositorio indica claramente las condiciones de acceso y uso?
- [ ] ¿Incluye una licencia de uso explícita (ej. Creative Commons)?
- [ ] ¿La documentación está disponible sin credenciales especiales?

## I - Interoperables (Interoperable)
- [ ] ¿Los datos están en formatos abiertos y estándar (CSV, JSON, XML)?
- [ ] ¿Las variables usan vocabularios controlados u ontologías reconocidas?
- [ ] ¿Se usaron clasificaciones estándar (DANE, ICD, UNESCO)?
- [ ] ¿Está documentada la estructura del dataset (diccionario de datos)?

## R - Reutilizables (Reusable)
- [ ] ¿Los metadatos incluyen toda la información para comprender y reutilizar el dataset?
- [ ] ¿Está documentado en un informe técnico (origen, curación, limitaciones)?
- [ ] ¿Incluye declaración de condiciones éticas y legales de uso?
- [ ] ¿La licencia permite expresamente la reutilización con o sin atribución?

## Formatos aceptados en esta carpeta
`.md`, `.pdf`, `.docx`
