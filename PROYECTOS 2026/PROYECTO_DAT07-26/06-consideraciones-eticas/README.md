# 06 · Consideraciones Éticas y Legales

## Qué va aquí
Soportes que respalden la sección 7 del Anexo 1 y las preguntas de autoevaluación del Anexo 4:

- Autorización de uso si los datos provienen de terceros.
- Evidencia de anonimización/desidentificación (metodología aplicada, no los datos mismos).
- Consentimientos informados, si aplica.
- Actas o avales de comité de ética institucional, si aplica.
- Restricciones éticas declaradas (uso restringido a ciertos fines, datos sensibles).

## Formatos aceptados
- `.pdf` (documentos firmados/escaneados)

## Nombre de archivo sugerido
`<CODIGO-PROYECTO>_soporte-etico_<descripcion-corta>.pdf`

## Nota de confidencialidad
No incluir datos personales identificables ni el dataset en esta carpeta — solo los soportes de autorización/consentimiento.
