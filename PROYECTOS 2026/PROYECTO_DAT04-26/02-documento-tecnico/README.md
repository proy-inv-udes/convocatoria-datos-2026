# 02 · Documento Técnico del Conjunto de Datos

## Qué va aquí
El Documento Técnico completo siguiendo las 10 secciones del **Anexo 1**:

1. Información general (título, autores, fecha, repositorio, DOI, licencia)
2. Descripción general del dataset
3. Origen y trazabilidad de los datos
4. Proceso de curación y transformación
5. Diccionario de datos (referencia cruzada a `03-diccionario-datos/`)
6. Cumplimiento de principios FAIR (referencia cruzada a `05-cumplimiento-fair/`)
7. Consideraciones éticas y legales (referencia cruzada a `06-consideraciones-eticas/`)
8. Análisis exploratorio del dataset
9. Limitaciones del dataset
10. Usos potenciales del dataset

## Formatos aceptados
- `.pdf` (versión final)
- `.docx` (versión editable)
- `.md` (opcional, si se documenta directamente en el repositorio)
