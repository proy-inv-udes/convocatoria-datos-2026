# 03 · Diccionario de Datos

## Qué va aquí
Tabla completa de variables del dataset (Anexo 1, sección 5), con al menos las columnas:

| Nombre de Variable | Tipo de Dato | Descripción | Valores posibles / Unidad | Notas |
|---|---|---|---|---|

## Formatos aceptados
- `.csv`
- `.xlsx`

## Obligatoriedad
Obligatorio como archivo aparte (no solo embebido en el documento técnico) cuando el dataset **supera 20 variables**.
