# 01 · Propuesta

## Qué va aquí
La propuesta completa presentada y aprobada en la convocatoria, siguiendo los componentes del **Anexo 4** (título, resumen ejecutivo, problema de investigación, estado del arte, pregunta de investigación, objetivo general, conocimiento generado, justificación, consideraciones éticas, metodología, productos esperados, impacto).

## Formatos aceptados
- `.pdf` (versión final firmada/aprobada)
- `.docx` (versión editable, opcional)

## Nombre de archivo sugerido
`<CODIGO-PROYECTO>_propuesta_v<AAAAMMDD>.pdf`

## No incluir aquí
- El dataset ni archivos de datos crudos.
- Versiones preliminares o borradores (usar control de versiones de Git para el historial).
